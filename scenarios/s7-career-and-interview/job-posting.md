# Junior Backend Developer (Python), CampusRoute team

**Synthetic Labs** (fictional company) · Istanbul, hybrid · Full-time · New graduates welcome

## About the team

CampusRoute helps 40,000 students at partner universities find rooms and walk the shortest route to class. We are four engineers and one designer. Our backend is a small, well-tested Python service; our next big items are a mobile client, step-free routing and "open now" badges.

## What you will do

- Build and test backend features in Python (routing, search, schedules).
- Write unit tests first or alongside code; keep the suite green.
- Review teammates' pull requests and explain your own.
- Read and gradually retire legacy code without breaking the kiosks that depend on it.
- Turn vague requests from student users into small, shippable tasks.

## Must have

- Solid Python fundamentals: data structures, standard library, exceptions.
- Experience writing automated tests (unittest or pytest).
- Comfortable with Git: branches, pull requests, resolving conflicts.
- Basic algorithms: graphs, shortest paths, complexity.
- Can explain a technical decision in clear English.

## Nice to have

- SQL and data modelling.
- Some JavaScript for small UI fixes.
- Experience with HTTP APIs (status codes, JSON, security basics).
- Accessibility awareness.

## Interview process

1. 30-minute intro call.
2. 25-minute take-home task (see `challenge/`), followed by a 20-minute walkthrough where **you explain your code**.
3. 45-minute technical interview with case studies.
4. Team chat.
